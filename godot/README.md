# NEON HAVOC — Godot 4 Source Project

This folder contains the Godot 4 implementation of **NEON HAVOC**.

## Requirements
- **Godot Engine 4.2+ or 4.3+** (Standard edition, Forward+ or Mobile renderer)

## How to Open and Run
1. Launch the Godot 4 editor.
2. Click **Import**, navigate to `d:/Games/MyGames/godot/project.godot`, and click **Import & Edit**.
3. Press **F5** (or the Play button in the top right) to run the game scene (`res://scenes/Main.tscn`).

## Controls (Configured in Project Settings > Input Map)
- **W / A / S / D** or **Arrow Keys**: Move Spark-01
- **Left Mouse Button**: Shoot primary Pulse Blaster
- **Q / Right Mouse Button**: Lightning Dash
- **E**: Aegis Orbital Shield
- **R**: Electric Shockwave
- **Space**: Spectrum Overdrive
- **Gamepad**: Full dual analog twin-stick shooter mapping
